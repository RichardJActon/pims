Development
===========

`Pims Source Code <https://github.com/RichardJActon/pims>`_

Tech Stack
----------

This application is developed using the Python web application framework 
`Flask <https://flask.palletsprojects.com/en/stable/>`_
and themed with `Bootstrap <https://getbootstrap.com/>`_
The database backend is `MongoDB <https://www.mongodb.com/>`_

This documentation is generated with `Sphinx <https://www.sphinx-doc.org/en/master/index.html>`_

Unit testing is done with `pytest <https://docs.pytest.org/en/stable/>`_

Python environment management is done with `uv <https://docs.astral.sh/uv/>`_
